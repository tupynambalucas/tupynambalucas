# Context7 MCP Integration

The `cortex/mcp/services/context7` directory defines integration instructions and router contexts for the Context7 Model Context Protocol (MCP) service.

---

## Technology Stack

- **Service Type**: Remote SaaS MCP Provider
- **Endpoint**: `https://mcp.context7.com/mcp`
- **Transport**: Streamable HTTP

---

## Features

- **Documentation Lookup**: Real-time framework and library documentation search.
- **Code Snippets**: Official usage examples and API syntax snippets.
- **Library ID Resolution**: Canonical package and library resolution.

---

## Available Tools

- `context7_resolve-library-id`: Resolves the canonical library ID for a given package name.
- `context7_query-docs`: Retrieves targeted documentation and code examples using the resolved library ID.
