# AI Agent Control Plane Runtimes

The `agents/` directory manages containerized terminal runtimes for AI coding agents operating within the AI Cortex ecosystem.

---

## Structure

- **[antigravity/](./antigravity/)**: Setup and environment scripts for Google Antigravity CLI.
- **[copilot/](./copilot/)**: Setup and environment scripts for GitHub Copilot CLI.
- **[shared/](./shared/)**: Common MCP configuration specifications and helper utilities.
