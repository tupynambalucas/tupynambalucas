# @tupynambalucas-dev/corporate-preset

Reusable Docusaurus preset encapsulating core plugins, AST transformers, navigation sidebars, and L10n translation synchronization for tupynambalucas.dev.

---

## Features

- **Decoupled Plugin Wrapper**: Injects multi-instance documentation (`docs`, `community`), single unified blog (`blog`), and static pages while isolating consuming services from Docusaurus boilerplate.
- **AST Project Variables Transformer**: Embeds `remark-project-variables` to dynamically resolve `tupynambalucas.dev`, `Tupynambalucas`, and other project metadata into rendered MDX content.
- **L10n Translation Orchestration**: Provides `plugins/crowdin/index.ts`. It gracefully bridges the GitHub App PR workflow by automatically copying L10n packages from namespace collections (`locales/`) into service `i18n/` directories at build time.
- **Unified Sidebars**: Exports preconfigured autogenerated sidebars for `defaultSidebar` and `community`.

---

## Usage

This preset is consumed by the `@tupynambalucas-dev/corporate-portal` service. It is not intended to be used outside the monorepo.

```ts
import type { MonorepoPresetOptions } from '@tupynambalucas-dev/corporate-preset/options';

// Inside docusaurus.config.ts
presets: [
  [
    require.resolve('@tupynambalucas-dev/corporate-preset'),
    {
      crowdin: { collection: 'portal' },
      docs: [/* ... */],
      blog: {/* ... */},
    } satisfies MonorepoPresetOptions,
  ],
];
```

## Operations & Scripts

Run commands from the monorepo root:

```bash
# Validate TypeScript type safety
pnpm kb:docusaurus:preset:typecheck

# Lint preset source code
pnpm kb:docusaurus:preset:lint
```
