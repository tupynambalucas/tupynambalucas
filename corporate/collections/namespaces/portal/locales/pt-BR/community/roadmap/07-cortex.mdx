Esta seção descreve os marcos estratégicos e o cronograma de desenvolvimento para o Workspace de processamento de IA Cortex consolidado.

## Marcos Concluídos

### Unificação do Workspace

- **Consolidação da Stack de IA**: O ecossistema de IA foi unificado ao co-alocar o API Ingress Gateway, o plano de dados do Model Context Protocol (MCP) e os runtimes de agentes sob `cortex/`. Configurações legadas removidas de `/tools` e `/platform`.
- **Reorganização de Domínios em Camadas**: O diretório wrapper redundante `core/` foi removido, reestruturando o Workspace em domínios planos no nível raiz: `gateway/`, `memory/`, `mcp/` e `agents/`.
- **Alinhamento de Portas do Gateway**: As portas de contêiner foram remapeadas e as configurações internas dos agentes foram atualizadas para rotear o tráfego através de Traefik -> AgentGateway na porta `8080`.
- **Resiliência na Inicialização do Banco de Dados**: Foram implementadas verificações de integridade de contêiner (healthchecks) dentro do manifesto do compose para garantir que os adaptadores downstream aguardem até que os bancos de dados estejam totalmente inicializados antes de tentar conexões de socket.

### Expansão do MCP e da Documentação

- **Novos Serviços MCP**: Foram deployados novos serviços MCP do Playwright e Kubectl junto com Github, Firecrawl, Grafana e Memory.
- **Migração de Documentação**: A referência de documentação standalone do AgentGateway foi migrada com sucesso para a estrutura de documentação do Workspace Cortex.

## Foco Planejado

### Subsistems de Memória RAG Vetorial do MongoDB (Alta Prioridade)

- **Layout do Banco de Dados**: Implemente uma camada de armazenamento persistente do MongoDB auto-hospedada dividida entre as coleções `chat_history`, `entities` e `relations`.
- **API & Core Libraries**: Codifique os modelos de validação de esquema do Mongoose e os endpoints da API do Fastify para lidar com o armazenamento de memória transacional e consultas de similaridade `$vectorSearch`.
- **Dashboard de Memória Visual**: Construa um dashboard interativo em React + Vite + Tailwind CSS dentro de `cortex/memory/services/web` para renderizar o Context Graph usando o React Flow.
- **Execução Exclusiva em Docker**: Empacote o sub-stack de memória para que os contêineres do banco de dados, da API e do dashboard Web sejam construídos e iniciados estritamente via Docker Compose.

### Validação e Desativação

- **Validação de Agente E2E**: Valide a integridade da montagem de volumes, a persistência de tokens OAuth e a conectividade de ferramentas a partir de shells de terminais de agentes containerizados.
- **Desativação da CLI do Host**: Remova as pastas de configuração legadas (`.agents/`, `.github/copilot/`) e desative as instalações de agentes globais no host assim que os ambientes de contêiner forem certificados.
