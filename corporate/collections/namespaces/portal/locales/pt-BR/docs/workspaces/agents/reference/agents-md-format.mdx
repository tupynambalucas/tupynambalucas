# Referência de Formato de AGENTS.md

Esta referência especifica a sintaxe, os esquemas estruturais e as restrições para arquivos de roteador de contexto `AGENTS.md`.

---

## 1. Especificação de Diretiva de Hierarquia de Contexto

O bloco XML `\<context-hierarchy>` deve ser o primeiro elemento em qualquer arquivo de Camada 2 ou Camada 3.

### Esquema

```xml
<context-hierarchy>
  <parent src="<RELATIVE_PATH_TO_PARENT_AGENTS_MD>" type="<PARENT_TYPE>" />
  <system-instruction>
    <IMPERATIVE_SYSTEM_INSTRUCTION>
  </system-instruction>
</context-hierarchy>
```

### Referência de Atributos

| Atributo | Obrigatório | Valores Válidos                         | Descrição                                                               |
| :------- | :---------- | :-------------------------------------- | :---------------------------------------------------------------------- |
| `src`    | Sim         | Caminho relativo                        | Caminho para o `AGENTS.md` pai (ex.: `../AGENTS.md`, `../../AGENTS.md`) |
| `type`   | Sim         | `global-rules`, `bounded-context-rules` | Categorização semântica das regras pai                                  |

---

## 2. Especificações de Camada

| Métrica                      | Camada 1 (Global)                        | Camada 2 (Bounded Context)                         | Camada 3 (Subdomínio)              |
| :--------------------------- | :--------------------------------------- | :------------------------------------------------- | :--------------------------------- |
| **Caminho do Arquivo**       | `/AGENTS.md`                             | `/[context]/AGENTS.md`                             | `/[context]/[sub]/AGENTS.md`       |
| **Limite de Linhas**         | 80 linhas                                | 120 linhas                                         | 100 linhas                         |
| **Tag de Hierarquia**        | Nenhum                                   | Sim (aponta para `/AGENTS.md`)                     | Sim (aponta para as Camadas 1 e 2) |
| **Linguagem Ubíqua**         | Não                                      | Sim                                                | Não (herdado)                      |
| **Habilidades Obrigatórias** | `agent-router-expert`, `markdown-expert` | Específicas de contexto (ex.: `docusaurus-expert`) | Não (herdado)                      |
| **Trechos de Código**        | Não                                      | Opcional                                           | Sim                                |

---

## 3. Restrições Universais

- **Idioma**: Apenas inglês (en-US).
- **Emojis**: Estritamente proibidos em todos os cabeçalhos, listas e textos corridos.
- **Caminhos**: Apenas links Markdown relativos (`./relative/path.md`). Caminhos absolutos do sistema de arquivos e URLs externas são estritamente proibidos.
- **Placeholders**: Proibidos (sem `TODO`, `TBD` ou seções vazias).
