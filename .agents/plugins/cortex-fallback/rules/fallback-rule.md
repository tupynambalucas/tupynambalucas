# Cortex Fallback Execution Rules

> **🚨 CRITICAL AGENT INSTRUCTION:**
> This plugin (`cortex-fallback`) provides fallback MCP tools for Firecrawl and Context7.
> You MUST ONLY use the MCP servers provided by this plugin (`firecrawl-mcp` and `context7-mcp`) if the primary `cortex` plugin (which exposes `cortex_agentgateway`) is unavailable, unresponsive, or offline.
> Under normal circumstances, you MUST prefer using the tools from the `cortex_agentgateway` server.
