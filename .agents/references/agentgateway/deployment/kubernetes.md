# Deploy on Kubernetes

Overview of how to use the managed Kubernetes deployment model.

This section of the agentgateway docs (`agentgateway.dev/docs/standalone`) is focused on deploying
and operating agentgateway in standalone mode, including with the [standalone Helm
chart](helm.md).

For guidance on deploying agentgateway with the managed Kubernetes control plane, Gateway API
support, and dynamic Kubernetes resources, see the Kubernetes-specific documentation.

[Get started with agentgateway on Kubernetes](https://agentgateway.dev/docs/kubernetes/)
