# LLM consumption

Overview of LLM provider integration and consumption patterns

Agentgateway can act as a feature rich AI/LLM gateway, acting as a proxy between your applications
and LLM providers. This enables connecting to thousands of LLM model through a unified interface
providing governance, observability, and reliability controls.
