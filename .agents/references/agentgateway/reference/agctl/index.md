# agctl CLI reference

Reference for the agctl command-line tool.

Reference for `agctl`, the command-line tool that you use to inspect and debug agentgateway. The
pages in this section are generated from the `agctl` source.

To install `agctl`, see [Install agctl](../../operations/agctl.md).

To generate a model cost catalog with `agctl costs import` and wire it into agentgateway, see [Model
costs](../../llm/cost-controls/costs.md).

> [!WARNING] Warning This feature is experimental. Try it out, see how it helps, and provide us feedback in GitHub or Discord. But keep in mind that it is subject to change and not supported for production.
