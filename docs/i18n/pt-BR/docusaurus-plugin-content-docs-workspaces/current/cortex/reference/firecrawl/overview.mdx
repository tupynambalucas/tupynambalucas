O servico **cortex-firecrawl-mcp** e um adaptador Fastify 5 stateless que conecta
o AgentGateway a API de inteligencia web do Firecrawl. Ele expoe a superficie
completa de capacidades do Firecrawl como seis ferramentas MCP sobre um transporte
Streamable HTTP.

---

## Topologia de Integracao

```text
AgentGateway (porta 8080)
  └── mcp-firecrawl (porta 8080, /mcp)
        └── Firecrawl API (cloud: https://api.firecrawl.dev  |  self-hosted)
```

Agentes nunca chamam este servico diretamente. Todas as requisicoes sao federadas
pelo AgentGateway, que aplica politicas de guardrails ExtMCP antes de despachar.

| Variavel            | Obrigatoria | Padrao                      | Descricao                                                                      |
| :------------------ | :---------: | :-------------------------- | :----------------------------------------------------------------------------- |
| `FIRECRAWL_API_KEY` |     Sim     | —                           | Chave de API para autenticacao com o servico Firecrawl.                        |
| `FIRECRAWL_API_URL` |     Nao     | `https://api.firecrawl.dev` | URL base da API Firecrawl. Substitua para apontar a uma instancia self-hosted. |
| `PORT`              |     Nao     | `8080`                      | Porta HTTP em que o servidor Fastify escuta.                                   |
| `NODE_ENV`          |     Nao     | `development`               | Flag de ambiente de execucao.                                                  |

### Roteamento de Host Local

Quando o servico detecta um hostname `localhost` ou `127.0.0.1` em um argumento
de URL de ferramenta, ele o reescreve automaticamente para `host.docker.internal`
para que as chamadas de ferramentas containerizadas alcancem processos na maquina
host do desenvolvedor.

Mapeamento automatico de porta para aplicacao usado durante a reescrita:

| Porta  | Aplicacao                                   |
| :----- | :------------------------------------------ |
| `3002` | Site de documentacao Docusaurus             |
| `5173` | Servidor de desenvolvimento Vite do hub-web |
| `3000` | Servico Fastify hub-api                     |

## Transporte

- **Caminho**: `/mcp`
- **Protocolo**: Streamable HTTP (especificacao MCP)
- **Modelo de sessao**: Stateless — `sessionIdGenerator` e definido como
  `undefined`. Cada POST para `/mcp` instancia um objeto `Server` MCP novo e
  o encerra apos a conclusao da resposta. Nenhum estado de sessao no servidor
  e retido entre requisicoes.

Busca Markdown limpo, HTML ou JSON estruturado de uma unica URL.

| :-------------------- | :-------------- | :---------: | :------------- | :------------------------------------------------------------------------------- |

| `formats`             | `array[string]` |     Nao     | `["markdown"]` | Formatos de saida: `markdown`, `html`, `rawHtml`, `links`, `screenshot`, `json`. |

| `includeTags`         | `array[string]` |     Nao     | —              | Tags HTML cujo conteudo e sempre incluido.                                       |
| `excludeTags`         | `array[string]` |     Nao     | —              | Tags HTML cujo conteudo e sempre excluido.                                       |

## Notas de Arquitetura

### Instanciacao de Servidor Stateless por Requisicao

Cada requisicao POST para `/mcp` cria uma instancia dedicada de `Server` do
`@modelcontextprotocol/sdk`. A opcao `sessionIdGenerator` e explicitamente
definida como `undefined`, desabilitando o gerenciamento de sessao MCP. Este
design:

- Elimina o crescimento de memoria no servidor por acumulacao de sessoes.
- Garante escalabilidade horizontal sem requisitos de afinidade.
- Significa que qualquer estado de sessao necessario por fluxos de trabalho
  multi-etapa deve ser mantido pelo chamador (AgentGateway ou o proprio agente).

### Firecrawl Self-Hosted

Defina `FIRECRAWL_API_URL` com o endereco interno de uma instancia Firecrawl
self-hosted para rotear todas as chamadas de ferramentas para fora da API em
nuvem. O `FIRECRAWL_API_KEY` ainda e necessario mesmo em implantacoes
self-hosted, a menos que a instancia desabilite a autenticacao.
