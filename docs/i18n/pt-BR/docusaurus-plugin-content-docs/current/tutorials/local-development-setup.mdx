# Configuração do Desenvolvimento Local

Neste tutorial, configuraremos o monorepo %PROJECT_DOMAIN% na sua máquina local. Ao final desta lição, você terá o ambiente de desenvolvimento completo rodando e pronto para você construir novas funcionalidades.

## Pré-requisitos

Antes de começarmos, garanta que você possui os seguintes itens instalados:

- Node.js versão 22
- PNPM versão 11
- Podman Desktop + Podman CLI + Extensão Compose (em vez de Docker)
- Minikube e kubectl (para o modo cluster Kubernetes)
- Skaffold (para pipelines de implantação do Kubernetes e recarregamento dinâmico/hot-reload)
- Git

---

## Passo 1: Clonar o Repositório

Primeiro, clone o repositório em seu workspace local e navegue para dentro dele.

```bash
git clone https://github.com/workspace/workspace.git
cd workspace
```

Você deve ver uma estrutura de diretórios contendo pastas como `docs`, `hub`, `cortex`, `profile`, `studio`, `platform` e `tools`.

---

## Passo 2: Instalar Dependências

Em seguida, instale as dependências do projeto. Como este é um monorepo, usamos o PNPM para instalar tudo de uma vez.

Execute o seguinte comando:

```bash
pnpm install
```

Quando o comando for finalizado, você verá uma saída confirmando que as dependências foram vinculadas ao content-addressable store.

---

## Passo 3: Configurar Variáveis de Ambiente

Cada workspace gerencia suas próprias configurações locais. Copie os arquivos de modelo `.env.example` para criar os arquivos de ambiente ativos:

```bash
# Configura as variáveis de ambiente da Infraestrutura
cp infrastructure/.env.example infrastructure/.env

# Configura as variáveis de ambiente do Hub
cp hub/.env.example hub/.env
```

:::info[Abra e Edite a Configuração]
Abra os arquivos `.env` recém-criados e adicione os tokens necessários (como `CLOUDFLARE_TUNNEL_TOKEN`) para acessar os serviços de nuvem.
:::

---

## Passo 4: Configurar a Máquina Podman

Antes de iniciar qualquer carga de trabalho de container, inicialize e inicie a máquina Podman padrão (que será usada pelo Minikube):

```bash
podman machine init
podman machine start
```

---

## Passo 5: Iniciar a Infraestrutura

Para construir todos os contêineres e implantar a stack completa no seu cluster Minikube local:

```bash
pnpm minikube:up
pnpm infra:dev
```

Este comando irá:

1. Iniciar o cluster Minikube.
2. Acionar o Skaffold para construir todas as imagens necessárias.
3. Hidratar os manifestos do Kustomize.
4. Implantar as camadas Platform, Cortex e Studio.
5. Transmitir logs e recarregar mudanças no código automaticamente (hot-reload).

---

## Passo 6: Verificar Acesso

Assim que os serviços estiverem em execução, verifique o acesso pelas rotas de borda do Cloudflare (ou `localhost` se estiver offline):

- **Grafana**: `https://grafana-dev.%PROJECT_DOMAIN%`
- **AgentGateway**: `https://agentgateway-mcp-dev.%PROJECT_DOMAIN%`
- **Penpot**: `https://penpot-dev.%PROJECT_DOMAIN%`
