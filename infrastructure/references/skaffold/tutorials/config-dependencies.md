Skaffold's [config dependencies](../design/config.md#configuration-dependencies) feature allows you
to import configurations defined across multiple `skaffold.yaml` files (even across repositories)
into a single configuration as its dependencies. This helps more readily integrate Skaffold with
multi-microservice and multi-repository applications.

For a guided Cloud Shell tutorial on setting up
[local dependencies](../design/config.md#local-config-dependency), follow:
