# ADR-003: Builds Multi-Stage com Turbo Prune e Cache do BuildKit

## Contexto

O monorepo contém múltiplos microsserviços em Node.js (por exemplo, servidores de API, serviços MCP, frontends web) gerenciados por meio de workspaces do PNPM e Turborepo. A execução concorrente desses builds de imagens Docker por meio do Skaffold resultava anteriormente em ineﬁciências:

1. Copiar todo o package.json raiz e os workspaces disparava invalidações de cache em todos os serviços sempre que um pacote não relacionado sofria alterações.
2. Comandos pnpm install independentes dentro de cada contexto de build do Docker desperdiçavam largura de banda e duplicavam entradas de cache para dependências idênticas.

## Decisão

Padronizaremos todos os Dockerfiles em Node.js no monorepo para utilizar uma arquitetura Multi-Stage aproveitando a poda do Turborepo e os montagens de cache do Docker BuildKit:

1. **Turborepo Prune (`turbo prune --docker`)**: Um estágio inicial de poda cria um snapshot mínimo e isolado do workspace específico e suas dependências internas (out/json e out/full).
2. **Mount de Cache Compartilhado do BuildKit (`id=pnpm-store-shared`)**: Os estágios `builder` e deployer utilizam `--mount=type=cache,id=pnpm-store-shared,target=/pnpm/store`. Isso permite que builds concorrentes do Skaffold compartilhem o mesmo repositório virtual do PNPM no daemon host, garantindo que os pacotes sejam baixados exatamente uma vez.
3. **Isolamento do Deployer (`pnpm deploy`)**: Os builds de produção utilizam `pnpm --filter \<workspace\> --prod deploy` para extrair um ambiente de produção autossuficiente, livre de dependências de desenvolvimento ou artefatos de código-fonte.

## Consequências

* Os tempos de build são reduzidos significativamente por meio de uma taxa de acerto de cache de camada de 90% e downloads de rede sem duplicação.
* As imagens Docker são incrivelmente leves, contendo apenas ativos compilados e dependências de produção.
* Alterações em um workspace não invalidam o cache de build do Docker de workspaces não relacionados.
