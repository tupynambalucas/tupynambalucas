O Workspace Hub contém todas as aplicações e pacotes relacionados ao site pessoal de desenvolvimento. É a vitrine principal para %PROJECT_DOMAIN%, fornecendo um portfólio profissional, engine de blog, inventário de habilidades técnicas e sistemas de tratamento de formulários de contato.

---

## Directory Structure

```text
hub/
├── services/
│   ├── api/          # Fastify 5 REST API
│   └── web/          # React 19 Single Page Application (SPA)
├── packages/
│   └── core/         # Shared Domain Model (SSOT)
```

---

## Core Components & Architecture

### `@repo/hub/core` (Domain SSOT)

Todas as configurações de schema, validadores e tipos principais de negócio são definidos neste pacote. Ao forçar tanto a REST API quanto o cliente Web a herdarem definições dessa camada central, aplicamos estrita paridade de Bounded Context e evitamos duplicação de modelos.

* **Technology Stack**: TypeScript, Zod.
* **Key Files**: Shared schema definitions for blog posts, projects, contact submissions, and user accounts.

### `@repo/hub/api` (Fastify 5 Engine)

Uma REST API de alta performance construída com Fastify v5, implementando uma arquitetura de software em camadas desacoplada.

* **Layered Design Flow**: `Controller ──> Service ──> Repository ──> Model`
* **Key Integrations**:
  * Conexão Mongoose com o banco de dados MongoDB local/em nuvem.
  * Gerenciadores de cache Redis para rate-limiting, armazenamento de sessões e consultas rápidas.
  * Hooks de validação Zod para requisições de entrada (body, query, params) e respostas de saída.
* **Strict Guidelines**:
  * Todas as operações assíncronas devem ser tratadas explicitamente.
  * Verificações estritas de booleanos são aplicadas em todos os controllers da API (`if (value === true)`).

### `@repo/hub/web` (React 19 Portal)

A interface de portfólio do usuário, frontend do blog e painel administrativo construídos em React 19 e compilados com Vite.

* **Technology Stack**: React 19, TypeScript, Vite, Zustand (state management), Studio Tokens (theme integration).
* **Design Parity**: Herda variáveis de tema, cores e constantes de layout diretamente do pacote `@repo/studio/assets`.
* **React 19 Features**: Implementa padrões modernos do React 19, utilizando o hook `use()` para carregamento de promises de recursos e garantindo comparações estritas de booleanos em todos os templates JSX.

## Database Configuration

Para suportar o armazenamento de submissões de contato e entrega de conteúdo do blog, o ambiente local executa um replica set do MongoDB orquestrado por Docker:

* **Replica Set Name**: `rs0`
* **Initiator Service**: `db-init` inicializa a configuração do replica set (`rs.initiate()`) após o MongoDB estar pronto.
* **Cache Layer**: O container Redis gerencia armazenamento chave-valor de alta velocidade e rate limiting.

## Workspace Scripts

Execute estes comandos a partir do diretório raiz para gerenciar o contexto do Hub:

| Command          | Action                                                                                                                  |
| :--------------- | :---------------------------------------------------------------------------------------------------------------------- |
| `pnpm hub:up`    | Inicia o banco de dados local (MongoDB Replica Set) e os containers Redis.                                              |
| `pnpm hub:dev`   | Executa o servidor da API (via `tsx watch`) e o cliente Web (via servidor de desenvolvimento do Vite) concorrentemente. |
| `pnpm hub:down`  | Para e remove os containers Docker.                                                                                     |
| `pnpm hub:reset` | Limpa os volumes do banco de dados e reinicia a infraestrutura.                                                         |
