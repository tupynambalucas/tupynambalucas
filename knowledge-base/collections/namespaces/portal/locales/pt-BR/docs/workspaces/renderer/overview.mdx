O Workspace Renderer contém o gerador de ativos dinâmicos genérico e o motor de compilação de documentos. Ele é responsável por compilar modelos em markdown em documentos prontos para produção em todo o monorepo e por gerar cartões SVG personalizados compatíveis com a marca.

---

## Estrutura de Diretórios

```text
renderer/
├── src/
│   ├── index.ts                     # Main runner executing active pipelines
│   ├── pipelines/                   # Pipelines Layer (SOLID/OCP architecture)
│   │   ├── types.ts                 # Shared pipeline schemas & types
│   │   ├── github-renderer.pipeline.ts # Standard renderer README compiler target
│   │   └── index.ts                 # Central active pipeline registry
│   ├── templates/                   # Domain-organized template directory
│   │   ├── cards/                   # Metrics-based and static SVG layouts
│   │   └── docs/                    # Textual markdown templates (e.g. README)
│   ├── renderers/                   # Compilation and layout engines (stats, headers)
│   └── utils/                       # Utilities (glob, font-encoding, template-fill)
├── generated/                       # Compiled development previews directory
│   ├── cards/                       # Flat SVG card theme copies (light/dark)
│   └── docs/                        # Subdivided theme document previews
├── package.json                     # Workspace dependencies and scripts
└── tsconfig.json                    # Configuration for TypeScript compilation
```

---

## Arquitetura Principal e Pipelines

Ao contrário de um script de geração ad-hoc simples, o Renderer possui uma **Pipeline Architecture** extensível que cumpre o Princípio Aberto/Fechado (SOLID).

* **Registro Extensível**: Alvos de compilação independentes (por exemplo, READMEs do renderizador do GitHub, manuais de diretrizes ou especificações de design systems) são registrados dentro de `src/pipelines/index.ts`.
* **Previa Separada por Tema**: Ao executar a compilação localmente, o gerador grava versões clara e escura totalmente renderizadas em `generated/cards/` e `generated/docs/`. As prévias em markdown claro fazem referência a ativos SVG claros, enquanto as prévias escuras fazem referência a SVGs escuros, garantindo testes de tema de alta fidelidade absoluta.

## Operações com Escopo

Execute estes scripts a partir da raiz do monorepo para gerenciar a pilha do gerador do renderer:

* `pnpm --filter @/renderer generate`: Executa as pipelines de compilação de documentos ativas localmente, gravando prévias em `generated/`.
* `pnpm --filter @/renderer clean`: Remove todos os arquivos compilados, caches e diretórios de build de saída.
* `pnpm --filter @/renderer typecheck`: Executa a validação de tipos do compilador TypeScript.
* `pnpm --filter @/renderer lint`: Executa verificações estáticas do ESLint.
