# Configuração de AI Agents

Este workspace gerencia o ciclo de vida, personas, ferramentas e conhecimento específico de domínio para agentes de IA operando dentro do monorepo `%PROJECT_DOMAIN%`. Adere estritamente à arquitetura de customização Antigravity (AGY).

## Visão geral

O diretório `.agents/` é fundamental para padronizar como os agentes alimentados por LLM compreendem e modificam a base de código.

- **Skills**: Personas especialistas isoladas e workflows.
- **Rules**: Restrições globais e específicas de contexto.
- **Plugins**: Definições de servidores MCP e roteamento de serviços.
- **Plans**: Memória de tarefas temporária e planos de execução de longo prazo.

Explore as seções abaixo para compreender a arquitetura de contexto hierárquico e as especificações para criar arquivos de roteamento `AGENTS.md`.
