# Configuração de AI Agents

Este workspace gerencia o ciclo de vida, personas, ferramentas e conhecimento específico de domínio para AI agents operando dentro do monorepo `%PROJECT_DOMAIN%`. Ele adere estritamente à arquitetura de customização Antigravity (AGY).

## Visão geral

O diretório `.agents/` é central para padronizar como os agents impulsionados por LLM compreendem e modificam a base de código.

* **Skills**: Personas de especialistas isoladas e workflows.
* **Rules**: Restrições globais e específicas de contexto.
* **Plugins**: Definições de servidores MCP e roteamento de serviços.
* **Plans**: Memória de tarefas temporária e planos de execução de longo prazo.

Explore as seções abaixo para compreender a arquitetura de contexto hierárquica e as especificações para a criação de arquivos de roteador `AGENTS.md`.
