O Workspace Knowledge Base gerencia o hub de documentação oficial para o projeto %PROJECT_DOMAIN%, conhecido como **%PROJECT_DOMAIN% Docs**. Construído sobre o Docusaurus v3, ele serve como o portal central de desenvolvedores, abrigando diretrizes arquiteturais, guias de estilo, documentos de planejamento de produto e changelogs e roadmaps automatizados de projetos.

## Architecture

O workspace implementa uma separação estrita entre o conteúdo em markdown puro e o mecanismo de renderização do Docusaurus:

```
knowledge-base/
├── docs/                     # Content Sub-domain (Engine-agnostic)
│   └── monorepo/
│       ├── handbook/         # General project handbook (Architecture, Style Guide, Guidelines)
│       ├── roadmap/          # Modular roadmap source documents
│       ├── releases/         # Blog-formatted release updates
│       ├── workspaces/       # Modular workspace descriptions (this section)
│       └── i18n/             # Internationalization configurations (Portuguese translations)
└── docusaurus/               # Engine Sub-domain
    ├── packages/
    │   ├── preset/           # Custom Docusaurus preset and plugins
    │   └── theme/            # Custom React theme overrides
    └── services/monorepo/
        ├── src/              # Custom react layout pages, assets, and styling components
        ├── tooling/          # Utility scripts (i18n sync, changelog/roadmap compilers)
        ├── sidebars.ts       # Main documentation sidebar rules
        ├── sidebarsRoadmap.ts
        ├── sidebarsWorkspaces.ts
        └── docusaurus.config.ts # Master Docusaurus site configuration
```

## Arquitetura Principal e Plugins Personalizados

O %PROJECT_DOMAIN% Docs está configurado com uma estrutura de documentação de múltiplas instâncias usando plugins do Docusaurus para segmentar as diferentes áreas do portal do desenvolvedor com barras laterais esquerdas independentes:

1. **Documentação Geral (Docs)**: Localizada em `docs/monorepo/handbook/` e mapeada para `/docs`. Regula briefs arquiteturais de alto nível, estratégias de segurança, guias de estilo de código e arquivos de visão mestre.
2. **Roadmaps Estratégicos (Roadmap)**: Localizados em `docs/monorepo/roadmap/` e mapeados para `/roadmap`. Regula marcos e objetivos específicos de contexto.
3. **Workspaces (Workspaces)**: Localizados em `docs/monorepo/workspaces/` e mapeados para `/workspaces`. Abriga descrições modulares detalhadas de cada contexto de pacote.
4. **Changelog (Blog)**: Localizado em `docs/monorepo/releases/` e mapeado para `/changelog`. Regula o histórico de versões e notas de lançamento.

## Internacionalização (i18n)

O %PROJECT_DOMAIN% Docs oferece suporte completo aos locales de inglês (`en`) e português (`pt-BR`). Os arquivos localizados espelham a estrutura dos documentos em inglês dentro da pasta `docs/monorepo/i18n/`:

* **Documentos Gerais**: `i18n/pt-BR/docusaurus-plugin-content-docs/current/`
* **Documentos de Roadmap**: `i18n/pt-BR/docusaurus-plugin-content-docs-roadmap/current/`
* **Documentos de Workspaces**: `i18n/pt-BR/docusaurus-plugin-content-docs-workspaces/current/`
* **Publicações de Changelog**: `i18n/pt-BR/docusaurus-plugin-content-blog/`

O mecanismo puxa essas traduções automaticamente em tempo de compilação usando o gancho de pré-compilação `tooling/sync-i18n.ts`.

## Compiladores de Raiz Automatizados

Para manter padrões limpos no repositório, o workspace de documentação possui compilações de scripts em tempo de build para gravar documentação em markdown unificada no nível da raiz do repositório:

* **`generate-roadmap.ts`**: Agrega todos os arquivos de contexto dentro de `roadmap/` e gera `/ROADMAP.md` na raiz do repositório.
* **`generate-changelog.ts`**: Analisa as postagens do blog de lançamento em `releases/` e gera `/CHANGELOG.md` na raiz do repositório.

Estes arquivos são gerados automaticamente e enviados via commit por meio do pipeline `.github/workflows/deploy-docs.yaml` a cada merge em develop.

## Scripts do Workspace

Execute estes comandos a partir do diretório raiz para gerenciar o contexto da documentação:

| Comando                                          | Ação                                                                                              |
| :----------------------------------------------- | :------------------------------------------------------------------------------------------------ |
| `pnpm kb:docusaurus:monorepo:dev`                | Inicia o servidor de desenvolvimento local do Docusaurus em `http://localhost:3002`.              |
| `pnpm kb:docusaurus:monorepo:build`              | Compila o build de produção do portal Docusaurus (executa validações de verificação de links).    |
| `pnpm kb:docusaurus:monorepo:generate:roadmap`   | Aciona manualmente a compilação dos documentos modulares de roadmap no arquivo raiz `ROADMAP.md`. |
| `pnpm kb:docusaurus:monorepo:generate:changelog` | Aciona manualmente a compilação das atualizações de lançamento no arquivo raiz `CHANGELOG.md`.    |
