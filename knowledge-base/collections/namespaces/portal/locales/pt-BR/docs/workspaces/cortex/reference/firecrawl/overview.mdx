O serviço **cortex-firecrawl-mcp** é um adaptador Fastify 5 sem estado que conecta o AgentGateway à API de inteligência web Firecrawl. Ele expõe toda a superfície de recursos do Firecrawl como seis ferramentas MCP em um transporte HTTP Streamable.

---

## Topologia de Integração

```text
AgentGateway (port 8080)
  └── mcp-firecrawl (port 8080, /mcp)
        └── Firecrawl API (cloud: https://api.firecrawl.dev  |  self-hosted)
```

Os agentes nunca chamam este serviço diretamente. Todas as solicitações são federadas através do AgentGateway, que aplica políticas de proteção ExtMCP antes do envio.

## Configuração

| Variável            | Obrigatório | Padrão                      | Descrição                                                                                   |
| :------------------ | :---------: | :-------------------------- | :------------------------------------------------------------------------------------------ |
| `FIRECRAWL_API_KEY` |     Sim     | —                           | Chave de API para autenticação com o serviço Firecrawl.                                     |
| `FIRECRAWL_API_URL` |     Não     | `https://api.firecrawl.dev` | URL base para a API do Firecrawl. Substitua para apontar para uma instância auto-hospedada. |
| `PORT`              |     Não     | `8080`                      | Porta HTTP em que o servidor Fastify escuta.                                                |
| `NODE_ENV`          |     Não     | `development`               | Flag do ambiente de runtime.                                                                |

### Roteamento de Host Local

Quando o serviço detecta um nome de host `localhost` ou `127.0.0.1` na URL de um argumento de ferramenta, ele o reescreve automaticamente para `host.docker.internal` para que chamadas de ferramentas conteinerizadas possam alcançar processos na máquina host do desenvolvedor.

Mapeamento automático de porta para aplicação usado durante a reescrita:

| Porta  | Aplicação                                   |
| :----- | :------------------------------------------ |
| `3002` | Site de documentação do Docusaurus          |
| `5173` | Servidor de desenvolvimento Vite do hub-web |
| `3000` | Serviço Fastify do hub-api                  |

## Transporte

* **Caminho**: `/mcp`
* **Protocolo**: HTTP Streamable (especificação MCP)
* **Modelo de sessão**: Sem estado — `sessionIdGenerator` é definido como `undefined`. Cada POST para `/mcp` instancia um objeto `Server` MCP novo e o remove após a conclusão da resposta. Nenhum estado de sessão do lado do servidor é retido entre as solicitações.

## Ferramentas

### `scrape`

Busca Markdown limpo, HTML ou JSON estruturado de uma única URL.

| Parâmetro             | Tipo            | Obrigatório | Padrão         | Descrição                                                                        |
| :-------------------- | :-------------- | :---------: | :------------- | :------------------------------------------------------------------------------- |
| `url`                 | `string`        |     Sim     | —              | URL de destino para scraping.                                                    |
| `formats`             | `array[string]` |     Não     | `["markdown"]` | Formatos de saída: `markdown`, `html`, `rawHtml`, `links`, `screenshot`, `json`. |
| `onlyMainContent`     | `boolean`       |     Não     | `true`         | Remove navegação, cabeçalhos, rodapés e conteúdo irrelevante.                    |
| `includeTags`         | `array[string]` |     Não     | —              | Tags HTML cujos conteúdos são sempre incluídos.                                  |
| `excludeTags`         | `array[string]` |     Não     | —              | Tags HTML cujos conteúdos são sempre excluídos.                                  |
| `waitFor`             | `number`        |     Não     | —              | Milissegundos para aguardar o conteúdo dinâmico antes da extração.               |
| `mobile`              | `boolean`       |     Não     | —              | Emula uma viewport de navegador móvel.                                           |
| `skipTlsVerification` | `boolean`       |     Não     | —              | Ignora a validação do certificado TLS.                                           |

| :------------------- | :-------------- | :---------: | :----- | :-------------------------------------------------- |
| `url`                | `string`        |     Sim     | —      | URL raiz para iniciar o rastreamento.               |
| `limit`              | `number`        |     Não     | `10`   | Número máximo de páginas para rastrear.             |
| `maxDiscoveryDepth`  | `number`        |     Não     | —      | Profundidade máxima de links a partir da URL raiz.  |
| `allowExternalLinks` | `boolean`       |     Não     | —      | Segue links para domínios externos.                 |
| `allowSubdomains`    | `boolean`       |     Não     | —      | Segue links para subdomínios do domínio raiz.       |
| `sitemap`            | `string`        |     Não     | —      | Tratamento de sitemap: `include`, `skip` ou `only`. |
| `includePaths`       | `array[string]` |     Não     | —      | Padrões glob de caminho de URL para incluir.        |
| `excludePaths`       | `array[string]` |     Não     | —      | Padrões glob de caminho de URL para excluir.        |

| :---------------- | :-------------- | :---------: | :------------- | :---------------------------------------------------------- |

## Notas de Arquitetura

### Instanciação de Servidor Sem Estado Por Solicitação

Cada solicitação POST para `/mcp` cria uma instância dedicada de `Server` do `@modelcontextprotocol/sdk`. A opção `sessionIdGenerator` é definida explicitamente como `undefined`, o que desativa o gerenciamento de sessão do MCP. Este design:

* Elimina o crescimento de memória no lado do servidor proveniente do acúmulo de sessões.
* Garante escalabilidade horizontal sem requisitos de afinidade.
* Significa que qualquer estado de sessão exigido por workflows de várias etapas deve ser mantido pelo chamador (AgentGateway ou o próprio agente).

### Firecrawl Auto-Hospedado

Defina `FIRECRAWL_API_URL` para o endereço interno de uma instância do Firecrawl auto-hospedada para direcionar todas as chamadas de ferramentas para longe da API em nuvem. A `FIRECRAWL_API_KEY` ainda é necessária mesmo para deploys auto-hospedados, a menos que a instância auto-hospedada desative a autenticação.
