# Rewrites

Rewrite the host or path of a request before agentgateway forwards it to a backend.

:::note[Note]

Modify URLs of incoming requests with rewrite**Rewrite**A traffic management feature that modifies
the authority (host) or path of requests before forwarding them to backends. policies.

For example, the following configuration modifies the request hostname to `%PROJECT_DOMAIN%` and the
request path to `/new-path`.

```
# yaml-language-server: $schema=https://agentgateway.dev/schema/config
mcp:
  port: 3000
  policies:
    urlRewrite:
      authority:
        full: %PROJECT_DOMAIN%
      path:
        full: /new-path
  targets:
  - name: everything
    stdio:
      cmd: npx
      args: ["@modelcontextprotocol/server-everything"]

# yaml-language-server: $schema=https://agentgateway.dev/schema/config
gateways:
  default:
    port: 3000
routes:
- policies:
    urlRewrite:
      authority:
        full: %PROJECT_DOMAIN%
      path:
        full: /new-path
  backends:
  - host: %PROJECT_DOMAIN%:443
```
