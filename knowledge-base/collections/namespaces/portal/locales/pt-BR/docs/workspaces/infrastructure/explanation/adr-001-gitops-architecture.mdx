# ADR-001: Arquitetura GitOps Híbrida de Helm + Kustomize

## Contexto

O deploy de manifests brutos do Kubernetes em múltiplos workspaces leva a configurações hardcoded e problemas de escalabilidade.

## Decisão

Adotaremos uma abordagem híbrida:

1. O **Helm** gerencia o template complexo e o empacotamento dos componentes de infraestrutura base.
2. O **Kustomize** atua como o gerenciador de overlay, injetando variáveis específicas de ambiente, arquivos `.env` locais (via `secretGenerator`) e substituindo dinamicamente campos como o Domínio do Projeto em objetos Ingress.
3. O **Skaffold** orquestra o loop de desenvolvimento local invocando o Kustomize com `--enable-helm`.

## Consequências

* Separação limpa da lógica de chart upstream das configurações locais.
* Deploy contínuo para novos forks de monorepo sem a edição manual de arquivos YAML.
