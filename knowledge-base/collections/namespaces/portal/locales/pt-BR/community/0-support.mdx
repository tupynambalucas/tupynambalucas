# Suporte e Canais

O ecossistema de desenvolvedores do %PROJECT_NAME% fornece canais dedicados para discutir arquitetura, relatar problemas e colaborar na evolução da base de código.

Antes de participar, analise nossas políticas de contribuição e códigos de conduta padrão.

## GitHub Issues

O GitHub Issues é o sistema oficial para rastrear bugs, relatórios de regressão e falhas de infraestrutura.

* Leia as [issues existentes](https://github.com/%GITHUB_ORG%/%REPOSITORY_NAME%/issues) antes de criar um novo ticket.
* Use Conventional Commits e modelos de relatório de bug padrão.

## Fóruns de Discussão

Para dúvidas de arquitetura, feedback de design tokens e RFCs do workspace:

* **GitHub Discussions**: O fórum principal para propostas técnicas e RFCs de monorepo.
* **Discord Community**: Canais em tempo real para orquestração de agentes, solução de problemas no servidor de desenvolvimento e anúncios.

## Solicitações de Recursos e Roadmap

Para analisar marcos planejados da plataforma ou propor adições arquiteturais:
