Esta seção descreve a arquitetura estratégica de monorepo, as configurações de catálogo e os objetivos lógicos de isolamento multi-tenant para o projeto %PROJECT_DOMAIN%.

## Foco de Desenvolvimento Atual: "Single-Instance Mastery"

**ESTRATÉGIA CRÍTICA:** Nossa prioridade imediata e absoluta é entregar uma **aplicação de instância única completa, 100% funcional e polida** (`@repo/hub/*`).

Embora tenhamos uma visão de longo prazo de nos tornarmos uma plataforma SaaS multi-tenant, **as complexidades arquiteturais de SaaS não devem ser implementadas neste estágio.** Todo o desenvolvimento atual (base de código, esquemas de banco de dados, UI/UX) deve permanecer focado em produzir a melhor versão possível de um sistema autônomo para uma ecovila. A transição para um modelo SaaS completo (Fase 6 do Plano Mestre) só será considerada após a aplicação de instância única estar estável e totalmente operacional.

## Marcos Concluídos

### Monorepo Architecture & Workspace Setup

* **Segregação de Workspaces no Monorepo**: Camadas de workspace estruturadas via PNPM Workspaces v11 e Turborepo, segregando os domínios `hub/`, `cortex/`, `studio/`, `tools/`, `renderer/`, `platform/` e `docs/`.
* **Orquestração de Tarefas de Alta Desempenho**: **Turborepo** integrado para orquestrar pipelines, permitindo o cache inteligente de alvos e a execução paralela de scripts.
* **Heranças de Configuração Unificadas**: Configurados `tsconfig.base.json` e `eslint.config.ts` em nível de raiz, extensíveis por pacotes do workspace via extensões do TSConfig e definições de array de configuração do ESLint.
* **Configuração do Node 22 & TypeScript ESM**: Todos os pacotes convertidos para usar Módulos ECMAScript (`"type": "module"`) e compilados com o alvo `ESNext` para suporte a sintaxe moderna.

### Contextos Delimitados e Segurança de Domínio

* **Isolamento Estrito de Contextos Delimitados**: Restrições de importação personalizadas do ESLint (`no-restricted-imports`) configuradas em `eslint.config.ts` para evitar dependências entre workspaces, garantindo uma lógica de negócios limpa e desacoplada.
* **Integração do Padrão Domain-Core**: Estabelecido `packages/core` em `hub/` como a Fonte Única da Verdade (SSOT) para modelos de dados e validadores de esquema.
* **Gerenciamento Unificado de Dependências via Catálogos**: Recurso de Catálogos do PNPM v11 integrado em `pnpm-workspace.yaml` para governar versões de ferramentas de terceiros (por exemplo, Fastify 5, React 19, TSX, ESLint) em todo o monorepo.

## Foco Planejado

* **Isolamento Multi-Tenant Lógico**: Garantir que instâncias e portais executem domínios de execução completamente isolados.
* **Evolução da Plataforma SaaS**: Transição de deploys de instância única para um modelo de marketplace multi-tenant centralizado, utilizando um Traefik Edge Router centralizado como ponto único de entrada para rotear dinamicamente requisições para ambientes de backend isolados.
