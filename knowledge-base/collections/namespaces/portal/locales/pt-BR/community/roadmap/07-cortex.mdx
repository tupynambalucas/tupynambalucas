Esta seção descreve os marcos estratégicos e o cronograma de desenvolvimento para o workspace consolidado de processamento de IA do Cortex.

## Marcos Concluídos

### Unificação do Workspace

* **Consolidação da Stack de IA**: O ecossistema de IA foi unificado ao co-locar o API Ingress Gateway, o plano de dados do Model Context Protocol (MCP) e os runtimes de agentes em `cortex/`. Configurações legadas foram removidas de `/tools` e `/platform`.
* **Reorganização de Domínios em Camadas**: O diretório de encapsulamento redundante `core/` foi removido, reestruturando o workspace em domínios planos no nível raiz: `gateway/`, `memory/`, `mcp/` e `agents/`.
* **Alinhamento de Portas do Gateway**: As portas dos contêineres foram remapeadas e as configurações internas dos agentes foram atualizadas para rotear o tráfego por meio de Traefik -> AgentGateway na porta `8080`.
* **Resiliência na Inicialização do Banco de Dados**: Verificações de integridade de contêineres foram implementadas dentro do manifesto compose para garantir que os adaptadores a jusante aguardem até que os bancos de dados estejam totalmente inicializados antes de tentar conexões de socket.

### Expansão do MCP e da Documentação

* **Novos Serviços MCP**: Novos serviços MCP do Playwright e Kubectl foram deployed juntamente com Github, Firecrawl, Grafana e Memory.
* **Migração da Documentação**: Toda a referência de documentação independente do AgentGateway foi migrada com sucesso para a estrutura de documentação do workspace do Cortex.

## Foco Planejado

### Subsistência de Memória RAG Vetorial do MongoDB (Alta Prioridade)

* **Layout do Banco de Dados**: Implemente uma camada de armazenamento persistente do MongoDB auto-hospedada dividida nas coleções `chat_history`, `entities` e `relations`.
* **API & Bibliotecas Principais**: Codifique modelos de validação de esquema do Mongoose e endpoints de API do Fastify para lidar com o armazenamento de memória transacional e consultas de similaridade `$vectorSearch`.
* **Dashboard de Memória Visual**: Construa um dashboard interativo em React + Vite + Tailwind CSS dentro de `cortex/memory/services/web` para renderizar o Context Graph usando o React Flow.
* **Execução Apenas em Docker**: Empacote a sub-stack de memória para que os contêineres do banco de dados, da API e do dashboard Web sejam construídos e iniciados estritamente via Docker Compose.

### Validação e Desativação

* **Validação de Agentes E2E**: Valide a integridade da montagem de volumes, a persistência de tokens OAuth e a conectividade de ferramentas a partir de shells de terminais de agentes conteinerizados.
* **Desativação da CLI do Host**: Remova pastas de configuração legadas (`.agents/`, `.github/copilot/`) e desative as instalações de agentes globais do host assim que os ambientes de contêiner forem certificados.
