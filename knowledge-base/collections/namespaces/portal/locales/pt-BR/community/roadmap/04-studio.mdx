Esta seção aborda o ambiente do Penpot, a automação de sincronização de design-tokens e o design de ativos de UI personalizados.

## Marcos Concluídos

### Ambiente de Design Colaborativo

* **Self-Hosted Design Hub**: Foi realizado o deploy de uma instância containerizada do Penpot v2 (espaço de trabalho de design com suporte do Aide) dentro do ambiente `@repo/studio/assets`, permitindo mockups de estilização colaborativa local seguros.
* **Centralized Design System Packages**: Estruturado `@repo/studio/assets` para servir como o pacote unificado para diretrizes de marca, estilos de tipografia, configurações de espaçamento e design tokens de paleta.

### Pipelines de Ativos

* **Branding Assets Export**: Ativos de exportação padronizados (incluindo vetores SVG, marcas de logotipo e folhas de cores) nos repositórios de projetos, fornecendo modelos brutos para aplicações web.
* **Brand Identity Realignment**: Reorganização da estrutura do workspace de ativos para estabelecer um namespace `brand` canônico (agrupando logotipos, paletas, favicons, banners, diretrizes) e renomeação do diretório de origens de design de `raw` para `sources`.
* **Cloud-Based Asset Hosting**: Implementação de um mecanismo CLI de sincronização bidirecional de ativos em `@repo/studio/assets/bucket`, permitindo a replicação contínua de origens de identidade de marca e ativos prontos para a web com o Cloudflare R2 Object Storage, eliminando ativos pesados do histórico do Git.

## Foco Planejado

* **Sync Integration**: Automatizar o pipeline para sincronizar tokens do Penpot diretamente para os design systems da base de código.
* **Extended Suite Assets**: Projetar bibliotecas de ativos de UI e marketing personalizados.
