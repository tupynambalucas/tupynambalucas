The Knowledge Base workspace manages the official documentation hub for the %PROJECT_DOMAIN% project, known as **%PROJECT_DOMAIN% Docs**. Built on Docusaurus v3, it serves as the central developer portal, housing architectural guidelines, style guides, product planning documents, and workspace references.

## Architecture

The workspace implements a strict separation between raw markdown content collections and the Docusaurus rendering engine:

```text
knowledge-base/
├── collections/                 # Content Sub-domain (Engine-agnostic)
│   └── namespaces/
│       └── portal/
│           └── content/
│               ├── blog/        # Changelogs and release posts
│               ├── community/   # Community guidelines and contributing docs
│               ├── docs/        # Monorepo architecture and workspace references
│               └── pages/       # Custom React landing pages
├── docusaurus/                  # Engine Sub-domain
│   ├── packages/
│   │   ├── preset/              # Custom Docusaurus preset and plugins
│   │   └── theme/               # Swizzled React theme components and overrides
│   └── services/
│       └── portal/              # The main Docusaurus service application
│           ├── src/             # Custom React layout components and assets
│           ├── docusaurus.config.ts # Master Docusaurus site configuration
│           └── sidebars.ts      # Main documentation sidebar rules
└── crowdin.yml                  # Translation synchronization configuration
```

## Internationalization (i18n) and GitOps

%PROJECT_DOMAIN% Docs fully supports English (`en`) and Portuguese (`pt-BR`) locales using a strict **Unidirectional GitOps Flow** managed by Crowdin.

- **Source of Truth (English)**: The GitHub repository stores only the English source documents inside the `collections/` directory.
- **Translation Engine (pt-BR)**: The Crowdin platform acts as the primary translation engine. It continuously generates translated artifacts and pushes them to the repository via automated Pull Requests targeting the `locales/` directory.
- **Build Isolation**: During the build pipeline, a custom plugin dynamically synchronizes the `locales/` content directly into the Docusaurus `i18n/` engine directory. The `i18n/` directory is intentionally ignored by Git (`.gitignore`) to isolate the rendering engine from the content collections.

## Workspace Scripts

Run these commands from the root directory to manage the documentation context:

| Command                           | Action                                                                                  |
| :-------------------------------- | :-------------------------------------------------------------------------------------- |
| `pnpm infra:dev`                  | Starts the entire Skaffold cluster, including the Docusaurus portal on port `3002`.     |
| `pnpm kb:docusaurus:portal:dev`   | Launches the standalone local Docusaurus development server at `http://localhost:3002`. |
| `pnpm kb:docusaurus:portal:build` | Compiles the production build of the Docusaurus portal and executes link validation.    |
