# Docs Content

This directory houses all technical and process documentation for the monorepo in plain Markdown and MDX.

## Domains

- **[monorepo/](./monorepo/)**: Content dedicated to explaining the global monorepo architecture, roadmap, and workspaces.
- **[github/](./github/)**: README templates and community standards.
- **[templates/](./templates/)**: Document structures consumed by the renderer.

By keeping these files decoupled from any specific static site generator, they remain portable and directly parsable by our AI memory (RAG) pipelines.
