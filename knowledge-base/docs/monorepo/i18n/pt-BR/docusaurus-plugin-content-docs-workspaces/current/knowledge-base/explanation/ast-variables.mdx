# Compilação de Variáveis AST

Para garantir que o monorepo permaneça totalmente genérico e passível de copy-paste para injeção de contexto de IA, nós impomos o uso de Variáveis AST (Abstract Syntax Tree) em todo o hub de documentação.

---

## 1. O Plugin `remark-project-variables`

Os autores de documentação e agentes de IA estão estritamente proibidos de usar hardcode para o domínio da marca (ex., `example.com`). Em vez disso, eles devem usar tokens agnósticos:

- `%PROJECT_DOMAIN%`
- `%PROJECT_NAME%`
- `%GITHUB_ORG%`

O plugin `remark-project-variables` intercepta o pipeline de compilação MDX do Docusaurus, percorre a AST do Markdown (`mdast`), e substitui esses tokens pelas configurações ativas encontradas em `project.config.json` antes de renderizar o HTML final.

Isso previne a "Alucinação de Marca" quando a IA extrai contexto usando indexação de memória RAG.
