# @monorepo/kb-docusaurus-preset

Reusable Docusaurus preset encapsulating core plugins, AST transformers, navigation sidebars, and Crowdin translation synchronization for %PROJECT_DOMAIN%.

---

## Features

- **Decoupled Plugin Wrapper**: Injects multi-instance documentation (`docs`, `community`), single unified blog (`blog`), and static pages while isolating consuming services from Docusaurus boilerplate.
- **AST Project Variables Transformer**: Embeds `remark-project-variables` to dynamically resolve `%PROJECT_DOMAIN%`, `%PROJECT_NAME%`, and other project metadata into rendered MDX content.
- **Crowdin Translation Orchestration**: Provides `plugins/crowdin/index.ts`, automatically copying unzipped translations from domain collections into service `i18n/` directories at build time.
- **Unified Sidebars**: Exports preconfigured autogenerated sidebars for `defaultSidebar` and `community`.

---

## Usage

This preset is consumed by the `@monorepo/kb-docusaurus-portal` service. It is not intended to be used outside the monorepo.

```ts
import type { MonorepoPresetOptions } from '@monorepo/kb-docusaurus-preset/options';

// Inside docusaurus.config.ts
presets: [
  [
    require.resolve('@monorepo/kb-docusaurus-preset'),
    {
      crowdin: { collection: 'portal' },
      docs: [/* ... */],
      blog: {/* ... */},
    } satisfies MonorepoPresetOptions,
  ],
];
```

## Operations & Scripts

Run commands from the monorepo root:

```bash
# Validate TypeScript type safety
pnpm kb:docusaurus:preset:typecheck

# Lint preset source code
pnpm kb:docusaurus:preset:lint
```
