O workspace Knowledge Base gerencia o hub oficial de documentação para o projeto %PROJECT_DOMAIN%, conhecido como **%PROJECT_DOMAIN% Docs**. Construído sobre o Docusaurus v3, ele serve como o portal central do desenvolvedor, abrigando diretrizes arquiteturais, guias de estilo, documentos de planejamento de produto, além de changelogs e roadmaps automatizados do projeto.

## Arquitetura

O workspace implementa uma separação estrita entre o conteúdo bruto em markdown e a engine de renderização do Docusaurus:

```
knowledge-base/
├── docs/                     # Sub-domínio de Conteúdo (Agnóstico de engine)
│   └── monorepo/
│       ├── handbook/         # Manual geral do projeto (Arquitetura, Guia de Estilo, Diretrizes)
│       ├── roadmap/          # Documentos de origem do roadmap modular
│       ├── releases/         # Atualizações de release formatadas em blog
│       ├── workspaces/       # Descrições modulares de workspaces (esta seção)
│       └── i18n/             # Configurações de internacionalização (traduções em português)
└── docusaurus/               # Sub-domínio da Engine
    ├── packages/
    │   ├── preset/           # Preset e plugins customizados do Docusaurus
    │   └── theme/            # Substituições de tema customizadas do React
    └── services/monorepo/
        ├── src/              # Páginas de layout React customizadas, ativos e componentes de estilização
        ├── tooling/          # Scripts utilitários (sync i18n, compiladores de changelog/roadmap)
        └── docusaurus.config.ts # Configuração mestre do site Docusaurus
```

## Core Architecture e Plugins Customizados

O %PROJECT_DOMAIN% Docs está configurado com uma estrutura de documentação multi-instância usando plugins do Docusaurus para segmentar as diferentes áreas do portal do desenvolvedor com barras laterais esquerdas independentes:

1.  **Documentação Geral (Docs)**: Localizada em `docs/monorepo/handbook/` e mapeada para `/docs`. Governa resumos arquiteturais de alto nível, estratégias de segurança, guias de estilo de codificação e arquivos de visão mestre.
2.  **Roadmaps Estratégicos (Roadmap)**: Localizado em `docs/monorepo/roadmap/` e mapeado para `/roadmap`. Governa marcos e objetivos específicos de cada contexto.
3.  **Workspaces (Workspaces)**: Localizado em `docs/monorepo/workspaces/` e mapeado para `/workspaces`. Abriga descrições detalhadas de cada contexto de pacote.
4.  **Changelog (Blog)**: Localizado em `docs/monorepo/releases/` e mapeado para `/changelog`. Governa o histórico de versões e notas de release.

## Internacionalização (i18n)

O %PROJECT_DOMAIN% Docs suporta totalmente as localidades Inglês (`en`) e Português (`pt-BR`). Os arquivos localizados espelham a estrutura dos documentos em inglês dentro da pasta `docs/monorepo/i18n/`:

- **Docs Gerais**: `i18n/pt-BR/docusaurus-plugin-content-docs/current/`
- **Docs de Roadmap**: `i18n/pt-BR/docusaurus-plugin-content-docs-roadmap/current/`
- **Docs de Workspaces**: `i18n/pt-BR/docusaurus-plugin-content-docs-workspaces/current/`
- **Posts do Changelog**: `i18n/pt-BR/docusaurus-plugin-content-blog/`

A engine puxa essas traduções automaticamente no momento do build usando o hook prebuild `tooling/sync-i18n.ts`.

## Compiladores Automáticos de Raiz

Para manter padrões de repositório limpos, o workspace de documentação apresenta scripts de compilação em tempo de build para gravar documentações unificadas em markdown no nível raiz do repositório:

- **`generate-roadmap.ts`**: Agrega todos os arquivos de contexto dentro de `roadmap/` e gera `/ROADMAP.md` na raiz do repositório.
- **`generate-changelog.ts`**: Analisa as postagens de blog de release sob `releases/` e gera `/CHANGELOG.md` na raiz do repositório.

Esses arquivos são automaticamente gerados e commitados através da pipeline `.github/workflows/deploy-docs.yaml` a cada merge para a branch develop.

## Scripts do Workspace

Execute esses comandos a partir do diretório raiz para gerenciar o contexto de documentação:

| Comando                                          | Ação                                                                                                  |
| :----------------------------------------------- | :---------------------------------------------------------------------------------------------------- |
| `pnpm kb:docusaurus:monorepo:dev`                | Inicializa o servidor de desenvolvimento local do Docusaurus em `http://localhost:3002`.              |
| `pnpm kb:docusaurus:monorepo:build`              | Compila a versão de produção do portal Docusaurus (executa validações de links).                      |
| `pnpm kb:docusaurus:monorepo:generate:roadmap`   | Dispara manualmente a compilação dos documentos de roadmap modulares no arquivo `ROADMAP.md` na raiz. |
| `pnpm kb:docusaurus:monorepo:generate:changelog` | Dispara manualmente a compilação das atualizações de release no arquivo `CHANGELOG.md` na raiz.       |
